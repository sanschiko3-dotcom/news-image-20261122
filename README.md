A program that renders one 1024x1024 newspaper front page summing up 22 November 2026 world news. The offline entrypoint uses only the Python standard library and copies the prepared image.

## Run it

Regenerate assets/entry.png with Pillow installed locally:

```sh
python3 render.py
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
